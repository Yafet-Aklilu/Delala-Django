# Delala

**A real estate rental platform designed to make finding and listing properties simpler.**

Delala is a real estate web application that connects property owners with people looking for rental properties, aiming to make the rental process more accessible and reduce unnecessary middleman friction.

🔗 **Live Demo:** https://delala-blush.vercel.app

## Overview

Delala is a full-stack project I have been developing, covering the product experience from interface design to frontend and backend implementation.

The goal is to create a straightforward platform where users can explore rental opportunities and property owners can present their listings in one place.
